# 全员 IP 中央厨房 PC 工作台

这是全员 IP 中央厨房的 PC 端工作台源码，包含：

- 手机号验证码登录
- AI 营销视频、案例展示、剪辑素材、参考脚本四个专区
- 视频封面、横竖版播放和多视频详情页
- 物料与参考脚本选择确认
- 数字老板 AI 生视频 / 参考视频改编任务编排
- 任务状态轮询和成品下载

## 本地运行

```bash
python3 server.py
```

默认绑定 `127.0.0.1`，本地访问地址由启动时的端口配置决定。

## 外部部署说明

GitHub 只负责保存和分发源码，GitHub Pages 不能运行本项目的 Python 服务端。完整能力需要同时部署：

1. 一个公网 HTTPS Python 后端，用于代理中央厨房接口、保存每个用户的会话、调用数字老板接口和轮询任务；
2. 一个静态前端，将 `static/app.js` 中的 API 地址配置为该后端地址；
3. 安全的服务端凭据方案。当前本地开发模式读取本机状态文件和本机数字老板登录态，不能直接用于多用户公网部署。

不要把中央厨房 token、数字老板 token、密码、短信验证码或本机状态文件提交到 GitHub。公网部署前还需要补齐：

- 多用户会话隔离；
- 服务端密钥/用户 token 的安全存储；
- HTTPS、限流、审计和任务归属校验；
- 数字老板长视频切片权限或其他获授权的分段上传通道。

当前仓库发布的是源码和本地运行版本，不宣称 GitHub Pages 已经具备完整生产能力。
